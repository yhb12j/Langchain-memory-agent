# LangChain Memory Agent

## Обзор фреймворков

Фреймворки вроде LangChain, LlamaIndex и Haystack не переобучают модель. Они добавляют поверх неё прослойку: память диалога, доступ к внешним данным, формат ответа и состояние между шагами.

### LangChain

Особенности: агенты, инструменты (`tools`), память и чекпоинты, структурированный вывод. LangGraph внутри экосистемы описывает логику как граф: узлы, рёбра и состояние, которое идёт вместе с процессом. Агент сам решает, вызвать функцию, сходить за данными или ответить текстом.

Где пригодится: чат-боты с историей диалога, сценарии записи на услуги, агенты с API и базами. Если нужен ответ в JSON или списком полей — формат задаётся схемой, без ручного парсинга текста.

### LlamaIndex

Особенности: индексация документов, баз и API, связка с LLM для RAG. Много готовых загрузчиков и нарезки текста на фрагменты. Поиск идёт по смыслу: вопрос превращается в вектор, из индекса поднимаются ближайшие куски.

Где пригодится: ответы по файлам компании, прайсу, FAQ, долгое хранение документов у бота. Когда задача — «найди в моих данных и ответь», а не сложная логика агента.

### Haystack

Особенности: поисковые и вопросно-ответные пайплайны. Хорошо стыкуется с Elastic и Hugging Face. Конвейер из компонентов: хранилище документов, retriever, reader.

Где пригодится: база знаний поддержки, FAQ, поиск по большому архиву текстов. Когда важнее стабильный поиск, чем агент, который сам выбирает инструменты.

Кратко: для диалога, tools и памяти удобнее LangChain, для документов и RAG — LlamaIndex, для поискового QA — Haystack.

---

Агент на LangChain / LangGraph: эксперт по породам и разведению кошек.

Держит диалог в памяти, вызывает инструменты и возвращает ответ строго списком фактов.

## Функционал и особенности

- модель `gpt-4o-mini` через ProxyAPI
- системный промпт эксперта по разведению кошек
- память диалога через `InMemorySaver` и `thread_id`
- контекст пользователя (`user_id`)
- структурированный вывод `ResponseFormat.cat_facts: list[str]`

### Инструменты

| Tool | Что делает |
| --- | --- |
| `get_cat_facts` | факты о породе: внешность, характер, содержание |
| `get_user_experience` | уровень опыта пользователя из контекста (`user_id`) |
| `get_breeding_notes` | допуск к вязке, размер помёта, генетические риски |

## Запуск

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
copy .env.example .env
```

В `.env` укажи ключ ProxyAPI. Затем:

```powershell
python main.py
```

Скрипт делает три вызова:

1. пользователь `1` спрашивает про золотую шиншиллу;
2. тот же `thread_id` — агент вспоминает предыдущую породу;
3. пользователь `2` в новом диалоге запрашивает факты и заметки по разведению.
